= Log Messages for git-store
:toc: left
:toclevels: 2

== Overview

The log-message catalogue of `git-store`
(xref:../../doc/specification/general.adoc#GDR-GEN-4[GDR-GEN-4]). Every message at level INFO, WARN or ERROR carries a
stable identifier of the form `GIT_STORE-<identifier>`, rendered by `LogRecord#resolveIdentifierString()` without
leading zeros; the identifiers follow the CUI `LogRecord` ranges (INFO 1-99,
WARN 100-199, ERROR 200-299). The messages are declared in
`de.cuioss.git.document.store.GitStoreLogMessages`.

No message carries anything xref:../../doc/specification/general.adoc#GDR-NFR-3[GDR-NFR-3] forbids: a message names a
provider id, a configuration key, a repository alias, a path, a reference, a commit id, an outcome or a number, never
a configured value, a key reference, key material, a token, a password, the user information of a remote, a content,
an e-mail address or a person name. The messages of a save name no path of the saved document, only the number of
conflicting paths.
Debug and trace messages carry no identifier and are not listed.

== INFO Level (1-99)

[cols="1,1,2,2", options="header"]
|===
|ID |Component |Message |Description
|GIT_STORE-1 |GIT_STORE |Selected the providers: signing key source %s, person directory %s, anchor provider %s
|Logged when the providers of the store were selected at start: the ids of the selected signing key source, person
directory and anchor provider, the provider ids only.
|GIT_STORE-2 |GIT_STORE |Saved repository %s, reference %s at commit %s
|Logged when the remote accepted an explicit save, or a draft without changes was saved as the tip of its existing
target branch
(xref:../../doc/specification/git-store.adoc#GDR-STORE-3[GDR-STORE-3]): the repository alias, the target reference and
the full id of the commit the target branch points at.
|GIT_STORE-3 |GIT_STORE |Did not save repository %s, reference %s: %s conflicting paths
|Logged when an explicit save conflicted and pushed nothing
(xref:../../doc/specification/git-store.adoc#GDR-STORE-4[GDR-STORE-4]): the repository alias, the target reference and
the number of conflicting paths, never a path.
|GIT_STORE-4 |GIT_STORE |Expired the drafts of repository %s: %s deleted
|Logged when the draft expiry deleted the drafts unchanged for `drafts.expiry` and collected the garbage
(xref:../../doc/specification/git-store.adoc#GDR-STORE-7[GDR-STORE-7]): the repository alias and the number of deleted
drafts, never a draft reference, which names a pseudonym.
|===

== WARN Level (100-199)

[cols="1,1,2,2", options="header"]
|===
|ID |Component |Message |Description
|GIT_STORE-100 |GIT_STORE |Refused the start: %s |Logged once when the start was refused, for a configuration or a
provider selection the store does not accept: the detail of the result, which names a key, an alias or a service
interface, never a value. A refused provider selection names the service interface and the configuration key
(`SigningKeySource: no provider with the id of signing.key-source`), never the configured id.
|GIT_STORE-101 |GIT_STORE |Did not complete the save of repository %s, reference %s: %s |Logged when an explicit save
ended without a commit on the remote for a reason other than a conflict
(xref:../../doc/specification/git-store.adoc#GDR-STORE-3[GDR-STORE-3]), for example a lease refused or a push rejected
on every attempt, an unreachable remote or invalid credentials: the repository alias, the target reference and the
name of the outcome, never a credential.
|GIT_STORE-102 |GIT_STORE |The garbage collection of repository %s failed: %s |Logged when the garbage collection
after the draft expiry failed (xref:../../doc/specification/git-store.adoc#GDR-STORE-7[GDR-STORE-7]): the repository
alias and the simple class name of the exception, never its message, which may carry a path.
|GIT_STORE-103 |GIT_STORE |Did not move the local branch of repository %s, reference %s after the accepted save: %s
|Logged when the remote accepted an explicit save but the local target branch could not be moved
(xref:../../doc/specification/git-store.adoc#GDR-STORE-3[GDR-STORE-3]): the repository alias, the target reference and
the simple class name of the exception, never its message, which may carry a path. The save is still `Saved`; the next
fetch mirrors the remote branch into the clone.
|GIT_STORE-104 |GIT_STORE |Skipped the garbage collection of repository %s: another collection holds gc.pid
|Logged when the draft expiry did not run its garbage collection because another collection holds the clone's
`gc.pid` (xref:../../doc/specification/git-store.adoc#GDR-STORE-7[GDR-STORE-7]): the repository alias. The expiry
ends in the passed-on `CONFLICT`, which may be retried.
|===

== ERROR Level (200-299)

`git-store` logs no message at level ERROR: an unexpected failure is returned as an outcome of the result.
