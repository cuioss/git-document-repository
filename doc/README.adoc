`git-document-repository` holds the base libraries for _Git as the Persistence of Versioned Documents_: a server-side
Git repository, reached through JGit in memory and without working trees, as the persistence of an application in
which users maintain versioned documents. The modules are released together and consumed separately.

This directory holds the design documentation of the libraries. A statement about an external product, standard or
law has to cite the source it was checked against; a statement without one is a defect.

[NOTE]
====
https://github.com/cuioss/TrailHand[TrailHand], the application built on these libraries, is documented in its own
repository (https://github.com/cuioss/TrailHand/blob/main/doc/README.adoc[`doc/` of `cuioss/TrailHand`]). It is not part
of the library documentation. Until 2026-11-20 that documentation was `doc/app/` of this repository.
====
