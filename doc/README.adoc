`git-document-repository` holds the base libraries for _Git as the Persistence of Versioned Documents_: a server-side
Git repository, reached through JGit in memory and without working trees, as the persistence of an application in
which users maintain versioned documents. The modules are released together and consumed separately.

This directory holds the design documentation of the libraries. Every statement about an external product, standard
or law cites the source it was checked against.

[NOTE]
====
`doc/app/` documents xref:app/README.adoc[CISOs-Friend], the application built on these libraries. It moves to its own
repository later and is not part of the library documentation.
====
