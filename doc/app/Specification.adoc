== Overview
_See Requirement link:Requirements.adoc#CIFR-GEN-1[CIFR-GEN-1: Categories as Configuration]_

This document is the entry point of the technical specification of CISOs-Friend. The requirements are in
link:Requirements.adoc[Requirements], the reasoning in the link:README.adoc#_concepts[concepts]. Every section of every
specification document carries a backtracking link to the requirements it realises and an implementation status.

All sections are `PLANNED`: no code exists yet. The status moves to `IN PROGRESS` and `IMPLEMENTED` with links to the
implementing classes and tests as the application is built.
