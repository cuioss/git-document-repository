== Integration
_See Requirement link:../Requirements.adoc#CIFR-NFR-6[CIFR-NFR-6: Native Image Verification]_

Status: PLANNED

Stack: `cisos-friend` (native image under test), Keycloak, Gitea, TSA stub. The first test class,
`NativeGitRoundTripIT`, runs fetch, save, release and push against Gitea and verifies tag and signature. It runs in
its own failsafe execution `native-round-trip`, declared before the execution of the remaining suites, with both its
`integration-test` and its `verify` goal bound to the `integration-test` phase. Maven runs executions of one phase in
declaration order, so a failure of this class fails the build before the remaining suites start. A second boot with
an invalid configuration must fail (boot-validation smoke test).

== Performance
_See Requirements:_

* _link:../Requirements.adoc#CIFR-NFR-1[CIFR-NFR-1: Index Size and Start Time]_
* _link:../Requirements.adoc#CIFR-NFR-2[CIFR-NFR-2: Save Latency]_

Status: PLANNED

* Fixture: a generated `samm-assessments` repository with 1,000 assessments of 90 answers (`cui-test-generator`).
* Index size: heap histogram after start, attributed to the index classes; must be < 100 MB.
* Start: time from process start to readiness `UP` with local repositories present; must be ≤ 60 s.
* Save latency, local mode: 1,000 sequential saves; p95 ≤ 500 ms.
* Save latency, remote mode: 1,000 sequential saves against the Gitea of the integration stack. The save service
  records the time spent in fetch and push per save (timer `cisos_friend_save_git_seconds`); the application's share
  is the save duration minus that time; p95 ≤ 500 ms.

Provisional: targets confirmed by the prototype measurement; until then the checks run in a `benchmarks` lane whose
results are reported, not gating.

== Concurrency
_See Requirement link:../Requirements.adoc#CIFR-NFR-3[CIFR-NFR-3: Concurrent Workshop]_

Status: PLANNED

Twenty virtual users, each saving ten times to its own practice of one assessment, in parallel; afterwards all 200
changes must be present on the working branch and no save result may be lost (every result is `SAVED` after the
library's retries, or `CONFLICT` only for tests that deliberately share a question).

== Security Tests
_See Requirement link:../Requirements.adoc#CIFR-NFR-4[CIFR-NFR-4: Inbound Input Security]_

Status: PLANNED

* Inbound validation: every REST resource, the MCP endpoint and the webhook endpoint run the generator-driven attack
  databases of `cui-http-testing` (path traversal, header injection, query manipulation); every attack must be rejected
  before reaching a service.
* MCP token tests: foreign audience, expired, wrong issuer, query-string token, missing scope, DPoP mismatch; each with
  the specified status and `WWW-Authenticate`.
* Credential leak scan: see link:mcp-server.adoc#_upstream_credentials[MCP Server, Upstream Credentials].
* Web: CSRF header missing, wrong `Origin`, CSP present on every HTML response.
