== Visual Language
_See Requirement link:../Requirements.adoc#CIFR-WEB-2[CIFR-WEB-2: Visual Language and Accessibility]_

Status: PLANNED

* `src/styles/tokens.css`: the token contract of `pm-web-app` (colour roles, type scale, 4 px spacing, radius, control,
  z-index, motion, breakpoints phone < 768, tablet 768–1279, desktop ≥ 1280); `:root` light, dark under
  `prefers-color-scheme` and `[data-theme]`.
* `src/lib/theme.ts`: light, dark, system; stored in `localStorage` key `cf_theme`.
* Inter variable font self-hosted in `static/fonts/` with its licence file; own icon set in `src/lib/icons/`.
* stylelint rule: no colour literal outside `tokens.css`.
* Contrast: an automated test computes WCAG 2.1 relative luminance for every text/background token pair in both themes;
  below 4.5:1 (3:1 for large text) fails.
* axe-core runs in `web-e2e` on every view; any `serious` or `critical` violation fails.

== Forms
_See Requirement link:../Requirements.adoc#CIFR-WEB-4[CIFR-WEB-4: Generated Forms]_

Status: PLANNED

`src/lib/forms/SchemaForm.svelte` renders a JSON Schema:

[cols="1,2"]
|===
|Schema construct |Component

|`string`, `maxLength` |`Field` (text)
|`string` with `format: date-time` |`Field` (date-time)
|`enum` |`Select`
|`boolean` |`Toggle`
|`array` of objects |`DataTable` with row editor
|`$ref` to a catalog (`x-catalog: service`) |`CatalogPicker`
|`x-asciidoc: true` |`AsciiDocField` with server-rendered preview
|`x-personal: true` |Field marked personal; hint shown
|===

Validation: the same schema runs in the browser (Ajv) and in the server; the server's field errors replace the
browser's on save.

== Editing
_See Requirement link:../Requirements.adoc#CIFR-WEB-5[CIFR-WEB-5: Drafts, Saving and Conflicts]_

Status: PLANNED

* Draft save: debounced, at most 5 s after the last change, `PUT /api/v1/drafts/{repository}/{id}`.
* Save: `POST /api/v1/documents/{repository}/{id}/save` with the blob ids loaded; result `SAVED`, `CONFLICT` (list of
  fields with own and other value), `SAVED_LOCALLY`.
* Event stream: `GET /api/v1/events` (`text/event-stream`); event `document-saved` with repository, id, fields; the
  open form refreshes the fields not edited locally.

== Review and Approval
_See Requirement link:../Requirements.adoc#CIFR-WEB-6[CIFR-WEB-6: Review and Approval]_

Status: PLANNED

* Diff: `GET /api/v1/documents/{repository}/{id}/diff?from=released` returns a structured diff of the YAML data; the
  view groups it by schema section.
* Approve: `POST /api/v1/approvals/{id}`; responses `APPROVED`, `STEP_UP_REQUIRED` (follow the address),
  `PASSKEY_REQUIRED` (run `navigator.credentials.get` with the options of
  link:authentication.adoc#_passkey_approval[Passkey Approval]).
* The approve button text names the level: "Approve (level 2: confirm with MFA)".

== Page Security
_See Requirement link:../Requirements.adoc#CIFR-WEB-8[CIFR-WEB-8: Page Security]_

Status: PLANNED

[cols="1,3"]
|===
|Header |Value

|`Content-Security-Policy`
|`default-src 'self'; script-src 'self' 'sha256-<bootstrap>'; style-src 'self'; img-src 'self' data:;
connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`

|`X-Content-Type-Options`
|`nosniff`

|`Referrer-Policy`
|`no-referrer`
|===

Anti-CSRF: every non-`GET` request carries `X-CSRF-Token` with the value from `GET /api/v1/session`; the server
compares it with the session's token and answers a mismatch with `403`.

AsciiDoc: rendered by the server in safe mode; the HTML is sanitised against an allow-list before it is returned.
