:toc: left

:source-highlighter: highlight.js

CISOs-Friend is the server application in which a development organisation maintains its OWASP SAMM assessments,
threat models, incident response reports and ISMS documents as versioned documents, on the Git server it already runs.
It is built on the libraries of `git-document-repository` and on Token Sheriff, and runs as a Quarkus native
application on Java 25.

[NOTE]
====
This directory documents the application, not the libraries. It lives here only until the application has a
repository of its own; then `doc/app/` moves there in one go and becomes that repository's `doc/`. It is therefore
self-contained: its diagrams are in `resources/diagrams/`, its decisions in `adr/`, and it links into the library
documentation only to the library concepts and requirements (`../concepts/`, `../Requirements.adoc`).
====

== Two User Interfaces

[cols="1,3"]
|===
|Interface |For

|*Web app*
|People: forms generated from the category schemas, dashboards, review and approval with step-up or passkey. A Svelte
single-page application with the visuals and UI structure of `pm-web-app`.

|*MCP server*
|AI agents acting for a user: reading, drafting and saving at signature level 1, requesting releases. An OAuth 2.1
protected resource; tokens are audience-bound and never passed through.
|===
