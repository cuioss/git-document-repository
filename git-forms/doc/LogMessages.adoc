= Log Messages for git-forms
:toc: left
:toclevels: 2

== Overview

The log-message catalogue of `git-forms`
(xref:../../doc/specification/general.adoc#GDR-GEN-4[GDR-GEN-4]). Every message at level INFO, WARN or ERROR carries a
stable identifier of the form `GIT_FORMS-<identifier>`, rendered by `LogRecord#resolveIdentifierString()` without
leading zeros; the identifiers follow the CUI `LogRecord` ranges (INFO 1-99,
WARN 100-199, ERROR 200-299). The messages are declared in
`de.cuioss.git.document.forms.GitFormsLogMessages`.

No message carries anything xref:../../doc/specification/general.adoc#GDR-NFR-3[GDR-NFR-3] forbids: a message names a
number, a directory or a commit id, never a configured or entered value, a token, a password, an e-mail address or a
person name.
Debug and trace messages carry no identifier and are not listed.

== INFO Level (1-99)

[cols="1,1,2,2", options="header"]
|===
|ID |Component |Message |Description
|GIT_FORMS-1 |GIT_FORMS |Loaded %s kinds of documents from %s
|Logged when the kinds of documents were loaded from configuration
(xref:../../doc/specification/git-forms.adoc#GDR-FORMS-1[GDR-FORMS-1]): the number of kinds and the source,
`directory <path>` for a configuration directory or `commit <id>` for a commit of a configuration repository, never a
configured value.
|GIT_FORMS-2 |GIT_FORMS |Performed a transition on the mechanism %s, commit %s
|Logged when a transition of a workflow was performed
(xref:../../doc/specification/git-forms.adoc#GDR-FORMS-5[GDR-FORMS-5]): the mechanism it maps onto
(`intermediate-save`, `save` or `release`) and the full id of the commit it wrote, the draft commit, the save commit or
the release commit; never the name of the transition, a state, a pseudonym or a claim.
|GIT_FORMS-3 |GIT_FORMS |Did not perform a transition on the mechanism %s: %s
|Logged when a transition of a workflow was not performed
(xref:../../doc/specification/git-forms.adoc#GDR-FORMS-5[GDR-FORMS-5],
xref:../../doc/specification/git-forms.adoc#GDR-FORMS-7[GDR-FORMS-7]): the mechanism it maps onto, or `none` when the
transition was not found, and the name of the outcome, for example `STEP_UP_REQUIRED`; never the name of the
transition, a state, a pseudonym, a claim or a finding.
|===

== WARN Level (100-199)

`git-forms` logs no message at level WARN.

== ERROR Level (200-299)

`git-forms` logs no message at level ERROR: an unexpected failure is returned as an outcome of the result.
