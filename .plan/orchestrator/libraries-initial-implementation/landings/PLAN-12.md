### Layer 3 — Correct

Two major defects, both on content a user can commit, so both reported to the operator in the same turn. By reading the rest holds: the YAML reader works on the event stream and refuses an alias, an anchor, an explicit tag and a second document before any node is built, so a billion-laughs document, a recursive alias and a custom tag cannot arise, no class is instantiated, the merge key is not enabled, a non-string and a duplicate key are refused, and a BOM and the line endings are stable (the leaf's reading of the reader); a `$ref` or `$dynamicRef` that leaves the schema file is refused at parse and the validator resolves only the bundled meta-schemas, so no network or file access is reachable from a reference; every validator is created per call, so no shared mutable state; `$ref` cycles are rejected by an explicit-stack search; and the violation messages quote a number, a type name or a format name, never an instance value (the library's own messages are replaced by key-only ones).
