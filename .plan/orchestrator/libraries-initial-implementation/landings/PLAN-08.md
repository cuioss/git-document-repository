### Layer 3 — Correct

No blocker and no major defect found in the write path. The four-step order holds by reading: fetch with explicit mirror refspecs and the technical-user credential; base = the local tip of the target (or `main` with a zero-id lease, or none); conflicts (per path, `expectedBlobId`, file/directory overlap) checked before any write; one commit whose only parent is the base, so no draft commit is reachable from a pushed reference; push with the lease of the base; only after the remote accepted does the local branch move (a failed local move after an accepted push is logged by class and still `Saved`); the draft is compare-and-deleted against the commit read once at the start. Reference names are built from regex-validated segments, so no traversal or injection; details and logs carry class names, aliases, references and counts, never a path, pseudonym or address.
